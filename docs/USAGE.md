# 使用手册

面向「已经跑起来了，但不确定怎么填」的使用者。安装步骤见 [README](../README.md)。

---

## 一、第一次打开

首次启动时 `private/` 会被自动创建，里面没有任何数据，页面显示的是占位方案（课程一/课程二/课程三）。

此时**先别急着打卡**，去「我的方案」把课表填进去——所有「第 N 周」「还有几天考」「哪门课断了两周」
都是从这张表推出来的，表是空的，分析也就没意义。

---

## 二、我的方案

这一页只放**你自己**的东西：课程、考期、目标、预算。它属于私有数据，保存后既改变页面显示，
也改变分析结论。

| 字段 | 填什么 | 影响哪些判断 |
| --- | --- | --- |
| 每周课外预算 | 一个你认为可持续的小时数，例如 15 | 本周投入超了会提示「已超预算」 |
| 单科目标分 | 单门课的期望分数 | 算出「离目标还差多少」 |
| 开学第一周的周一 | 那学期第 1 周周一的日期 | 所有「第 N 周」的口径 |
| 那是第几教学周 | 该日期对应第几周 | 同上；用来对齐学校口径 |
| 课程 · 课程名 | 你自己的叫法 | 出现在所有下拉与统计里 |
| 课程 · 考试日期 | 期末考试日期 | 倒计时、「期末挤压」判断 |
| 课程 · 考试时段 | 例如「第 19 周 周四下午」 | 只用于展示 |
| 专项 | 课程之外的第二条线，可留空 | 见下 |

### 专项（可选）

语言考试、竞赛、作品集、考研科目……都属于「课程之外的第二战场」。它有三个可自定义的计数器：

- **计数器名字由你起**：例如「单词 / 精听 / 真题」「背诵 / 刷题 / 套卷」「阅读 / 写作 / 口语」。
- **周目标**：每个计数器每周想完成多少。
- **名称留空 = 不启用**：整块不显示，分析里也不会出现这一栏。

专项的设置跟课程是两套逻辑：课程看长期进度，专项看本周缺口和距考期的剩余量。

## 三、今日打卡

每天填一次，十秒钟。四个字段：

| 字段 | 说明 | 参与什么判断 |
| --- | --- | --- |
| 投入小时 | 今天课外投入的总小时 | 本周预算、单日透支、趋势曲线 |
| 睡眠 | 昨晚睡了几小时 | 「睡眠不足 6 小时」 |
| 课程推进 | 每门课今天推进到哪一级（0–3） | 课程断层、「还没开始」 |
| 卡点 | 今天卡在哪（自由文本） | 周复盘参考 |

**推进等级**不必精确，只要求跨天可比：

- `0` 没碰
- `1` 看了/听了一部分
- `2` 做了题/推进了一节
- `3` 完成了计划中的一块

如果某个字段你用不上（比如不记睡眠），去「设置 → 功能选择」把它关掉。
**关掉之后它既不显示，也不再参与分析**——不会出现「你刚关掉，第二天却被提醒睡眠不足」。

## 四、作业台账

一条作业最少填三项：课程、标题、截止日。

- **标题写具体点。** 「第 5 章习题 3/7/11」比「作业」有用得多——一周后你还看得懂。
- **状态**：`todo` 待做 / `doing` 在做 / `done` 已完成 / `graded` 已评分。
- **预计与实做工时**：想估时间管理就用，不填也不影响其他判断。
- **逾期会自动排到分析第一位**，并挤掉其他所有建议——这是刻意的，逾期的事优先。

「导出作业清单」会下载一个 JSON，可以交给外部定时任务做提醒。

---

## 五、本周复盘

周末填一次，这是全套里唯一需要静下心写的地方。

- **周负荷**：本周实际投入小时。
- **三项优先任务**：下周最重要的三件事，不超过三件。
- **五问复盘**：本周进展 / 卡在哪 / 原因 / 下周打算。
- **原因分类**：估算偏差、外部打断、负荷过重、动力不足、无明显原因——这个分类会进统计，
  连续几周都是同一个原因，说明要改的是方法而不是更努力。

---

## 六、记录趋势

只读页。近 14 天投入曲线、全部打卡历史、周复盘存档。用来回答「我这两周到底在干什么」。

---

## 七、节点

- **考试周起始**：期末周从哪天开始。
- **外部节点**：材料截止、申请提交、竞赛报名等有明确日期的事件。
- **里程碑**：规划拆解出来的阶段目标，界面只读。
- **倒计时**：离每个节点还有几天。

## 八、设置

### 个人资料

姓名、学校、专业、年级、学期、学习目标。**全部默认为空**，填什么才显示什么。

如果你只想自己知道，不勾「在标题栏显示身份备注」即可——数据仍在，但界面上不出现。

### 功能选择

勾掉用不到的页签和模块。三条规则：

1. **设置页本身关不掉**，所以永远有入口改回来。
2. **关掉 ≠ 藏起来**：对应的分析规则会一起跳过。
3. **改完当场生效**，保存后写进 `private/profile.json`，刷新仍在。

### 外观主题

四套配色，点一下立刻换，不用刷新：

| 主题 | 什么时候用它 |
| --- | --- |
| 圆石 · 书页 | 默认，暖米色，白天长时间看不刺眼 |
| 下界 · 熔岩 | 深底橙字，晚上用 |
| 雪原 · 云杉 | 冷白松绿，强光下对比清楚 |
| 沙漠 · 砂岩 | 土黄砂岩，喜欢暖调子 |

主题**只改颜色和底纹，不改尺寸和排版**——换主题页面不会跳一下，卡片宽窄完全一样。
选择存在 `private/profile.json` 的 `appearance.theme`，换设备登录不需要重设。

> 顺带一提：主题与「功能选择」是两套独立的设置，一个管长什么样，一个管显示什么，
> 互不影响；改了一个不会把另一个重置。

## 九、命令行与运维（可选）

```bash
npm start              # 只起服务（127.0.0.1:3000，最保守）
npm run launch         # 起服务 + 守护 + 局域网地址检测（0.0.0.0）
node healthcheck.js    # 守护跑一次，结果打到屏幕并追加到 health.log
node healthcheck.js --daemon   # 每 5 分钟检查一次，挂了自动拉起
node notify.js         # 推送渠道自检
```

### 手机访问

1. 电脑和手机连同一个 WiFi。
2. `npm run launch`（或双击 `start.bat`），地址会写进 `private/tunnel-url.txt`。
3. 手机打开 `http://<电脑内网IP>:3000/?k=<口令>`，只需带一次参数，之后浏览器记住 30 天。

> 内网 IP 会随 WiFi 变化（DHCP）。换了网络就重新看一眼 `tunnel-url.txt` 或管理台。

### 管理台

浏览器打开 `/admin.html`：服务状态、数据条数、启动器与隧道状态、日志尾巴、停止/重启按钮。

### 备份

拷贝整个 `private/` 目录即可，它包含全部数据、口令和地址记录。

恢复就是把它拷回去、重启服务。**建议每周拷贝一次到别的地方**——分层解决的是「谁能看」，
不解决「丢了怎么办」。

## 十、排错

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 页面白屏 | 直接双击了 `index.html` | 必须通过 HTTP 打开，见 `npm start` |
| 页面提示「没有权限」 | 口令模式生效，但没带参数 | 用 `?k=<token>` 打开一次；口令在 `private/config.json` 的 `token` |
| 不知道口令是什么 / 换了口令不生效 | 首启自动生成过；口令只在启动时读一次 | 看启动日志 `access` 那行，或打开 `private/config.json`；改完必须重启服务 |
| 打开就是空数据 | 没填「我的方案」 | 先去填课表 |
| `npm run verify` 里浏览器检查失败 | 没有可用的 Chrome | 装 Chrome，或只跑 `npm test` / `npm run api` |
| Windows 双击 `start.bat` 没反应 | 它是静默启动，本来不弹窗 | 看 `launch.log` / `health.log`，或开管理台 |
| 提示找不到 node | 机器上没装 Node，也没有便携运行时 | 跑一次 `make-portable.bat`，或装 Node.js ≥ 18 |
| 手机打不开 | 不在同一 WiFi，或防火墙拦了端口 | 检查防火墙入站规则；跨网络需要隧道模式 |
| 两个设备改的数据不一致 | 删除不传播（已知限制） | 避免在两端同时删除同一条；以最后一次编辑为准 |
